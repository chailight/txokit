# txokit

a minimal mod that allows the txo to be a destination for sixolet's matrix mod and toolkit mod system for the monome norns. 
The main control for parameters is sixolet's toolkit mod - once you should see a toolkit menu in the global params page and you can, for example select lfo 1 and say whether it is clocked or not (click k3 to toggle) and then you’ll be able to adjust the clock division (or the frequency in Hz) in the next parameter below. Once you’ve set up LFO 1 to be a clocked LFO, you need to go the the matrix mod settings on the systems page in order to map LFO 1 to say txo CV1 as a destination - you can also trim the value of the LFO at that point.

This is kinda hard to describe in text and the matrix mod is a little confusing at first but once you’ve mapped a toolkit LFO to a txo output then you can just go back to the toolkit params menu and make any adjustments you need there.
